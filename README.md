
# Cadastral-nums-API

Сервис для обработки кадастровых номеров с эмуляцией внешнего сервиса.

Этот проект реализует простой, но показательный бэкенд-сервис на **FastAPI**. Он принимает запросы с кадастровым номером и координатами, эмулирует обращение к внешнему (возможно, медленному) сервису, сохраняет всю историю в **PostgreSQL** и предоставляет API для её получения.

## 🚀 Основной функционал

Сервис решает ключевую задачу: принятие запроса, его обработка через внешний сервис и сохранение истории.

*   **POST `/query`**: Принимает кадастровый номер, широту и долготу. Отправляет данные на эмулируемый внешний сервис, сохраняет запрос и ответ в базу данных, возвращает результат клиенту.
*   **GET `/history`**: Возвращает историю всех обработанных запросов, сохранённых в базе данных.
*   **GET `/ping`**: Простой эндпоинт для проверки, что основной сервис работает.
*   **GET `/result`**: Эндпоинт, который эмулирует работу внешнего сервиса. Возвращает случайное `true` или `false` (именно к нему обращается основной сервис по `/query`).

## 🛠️ Стек технологий

Проект построен на современном асинхронном стеке.

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Язык** | Python 3.14 | Основной язык разработки. |
| **Веб-фреймворк** | FastAPI | Создание REST API, автодокументация, асинхронность. |
| **База данных** | PostgreSQL | Реляционная СУБД для надежного хранения истории запросов. |
| **Драйвер БД** | asyncpg | Высокопроизводительный драйвер для асинхронной работы с PostgreSQL. |
| **Миграции** | Alembic | Управление схемой базы данных (создание таблиц, обновления). |
| **Контейнеризация** | Docker, Docker Compose | Упаковка приложения и зависимостей, простой запуск всех сервисов одной командой. |

## 🐳 Запуск через Docker Compose (Рекомендуемый способ)

Это самый простой способ поднять весь проект, так как он автоматически запускает и само приложение, и базу данных PostgreSQL.

1.  **Убедитесь, что у вас установлены Docker и Docker Compose.**
2.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/PierPankratc/Cadastral-nums-API.git
    cd Cadastral-nums-API
    ```
3.  **Запустите контейнеры из корня проекта:**
    ```bash
    docker compose up --build
    ```

    После успешного запуска все сервисы будут подняты:
    *   Основной API: `http://localhost:8000`
    *   Эмулируемый внешний сервис: `http://localhost:8001`
    *   PostgreSQL: `localhost:5432` (логин/пароль: `postgres`)

## 💻 Локальный запуск без Docker

Если вы предпочитаете запускать сервисы напрямую на своей машине.

### 1. Установите зависимости
Убедитесь, что у вас установлен Python 3.13+ и менеджер пакетов `uv` (рекомендуется) или `pip`.

**С `uv`:**
```bash
uv sync
```

**С `pip`:**
```bash
python -m pip install -e .
```

### 2. Настройте переменные окружения
Создайте файл `.env` в корне проекта или задайте переменные напрямую в терминале.

*   **`DSN`**: Строка подключения к вашей локальной PostgreSQL. Убедитесь, что база данных `test_case` создана.
*   **`FAKE_SERVICE_URL`**: URL, по которому будет запущен ваш эмулируемый сервис.

### 3. Запустите базу данных
У вас должен быть запущен PostgreSQL, и в нём создана база данных с именем, указанным в `DSN` (например, `test_case`).

### 4. Запустите сервисы
Вам нужно запустить эмулируемый сервис и основной API в разных терминалах.

**Терминал 1 (Запуск эмулируемого сервиса):**
```bash
uvicorn fake_servis:fake_servis --host 127.0.0.1 --port 8001
```

**Терминал 2 (Запуск основного API):**
```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

После этого API будет доступен по адресу `http://localhost:8000`.

## 🧪 Пример использования

После запуска сервиса вы можете отправить запрос, используя `curl`.

```bash
curl -X POST http://localhost:8000/query \
  -H "Content-Type: application/json" \
  -d '{"cadastral_number":"12345678","latitude":55.75,"longitude":37.61}'
```

**Ожидаемый ответ:**
```json
{
  "status": "success",
  "result": true
}
```

Чтобы просмотреть историю запросов, перейдите в браузере по адресу `http://localhost:8000/docs` для автодокументации Swagger UI или выполните запрос:

```bash
curl http://localhost:8000/history
```
